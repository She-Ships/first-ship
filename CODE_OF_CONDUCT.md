# Code of Conduct

This project follows the she[ships] community values: this is a space to grow, collaborate, and ship real software together — including the messy first attempts.

- Be kind, especially to people posting their first PR ever.
- No question is too basic to ask.
- No gatekeeping over "real" contributions — a fixed typo and a new feature both count.
- Critique code, not people.
- If you see someone struggling, offer help before judgment.

Violations can be reported to the she[ships] organizers on [dev.to](https://dev.to/sheships).
