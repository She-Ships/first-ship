# 🚢 First Ship

A curated list of beginner-friendly open-source issues, vetted specifically to help someone land their **first merged pull request.**

Maintained by [she[ships]](https://dev.to/sheships) — a community of women, trans, nonbinary, and gender-diverse people who build, learn, create, and ship in tech.

## Why this exists

"Good first issue" labels exist all over GitHub, but they're inconsistent — some are genuinely approachable, some assume context a newcomer doesn't have, and plenty are stale or already claimed. This list is different because every entry has actually been reviewed by a community member before it's added: is it still open, is it really beginner-friendly, and does it come with enough context that someone can start without guessing.

If you've never merged a PR before, this list is for you. If you've found or vetted a good beginner issue somewhere, this list needs you too.

## The list

See [`ISSUES.md`](./ISSUES.md) for the current set of vetted issues.

| Column | What it means |
|---|---|
| Project | Repo name, linked |
| Issue | Direct link to the issue |
| Stack | Language/framework involved |
| Difficulty | 🟢 Easy · 🟡 Medium (first-PR-friendly but not trivial) |
| Notes | Anything a newcomer should know before starting |
| Added by | Who vetted this entry (accountability + someone to ask) |

## How to use this list

1. Pick an issue that matches a stack you know or want to learn.
2. Comment on the GitHub issue to claim it (check it's not already claimed).
3. If you get stuck, ask in the she[ships] community — that's what "added by" is for.
4. Shipped something? Tell us. We want to hear about it, first-timer nerves and all.

## How to contribute an issue

See [`CONTRIBUTING.md`](./CONTRIBUTING.md) for the vetting checklist and PR process. Short version: find a genuinely good first issue, confirm it's still open and unclaimed, fill out the template, open a PR.

## Code of Conduct

This list follows the [she[ships] Code of Conduct](./CODE_OF_CONDUCT.md). Be kind. Everyone here started somewhere.
